PART 1 — HARDWARE & INPUT DEVICES (Lesson 2.1)

1.1 Introduction (Why learn computers?)

  • Computers are an essential part of everyone's life today.
  • They are used in almost every field, and new uses are discovered every day.
  • Places that use computers: homes, offices, schools, colleges, universities, hospitals, shops, businesses, industries, banks, railway stations, bus stations, airports, research centers, and other organizations.
  • Since most daily activities are done by computers, everyone should have basic computer knowledge.

1.2 What is a Computer?

  • A fast calculating device that does arithmetic operations.

  • But it is more than a calculator. It can do any work involving arithmetic AND logical operations on data.

  • The basic flow:

    INPUT (get data) → PROCESS (follow instructions) → OUTPUT (give information)

1.3 What is Hardware?

  • Hardware = any physical component of a computer (you can see and touch it).

  • Many kinds of hardware exist today.

  • Hardware is classified by its function in the computer system:

    1. Input devices
    2. Output devices
    3. Storage devices
    4. Communication devices

    (Note: the slide says "three categories" but actually lists these four.)

1.4 What this unit covers / Objectives

The unit deals with: anatomy of a computer, input/output/storage devices, types of computers, and hardware troubleshooting & diagnosis.

After studying, you should be able to:

  • Explain the anatomy of a computer
  • Explore various input, output, and storage devices
  • Describe temporary and permanent storage devices
  • Explain the different types of computers
  • Explain various computer troubleshooting

1.5 Anatomy of a Computer

Hardware vs Software

  • Internal design differs per model, but the basic components are the same in all computers.
  • A computer needs BOTH hardware and software to work.
Hardware Software
What it is Mechanical & electronic devices you can see and touch Programs, operating systems, and data stored in memory/storage
Examples Keyboard, Monitor, DVD Java, Microsoft Office, Open Office

Summary line: Hardware = physical parts. Software = programs needed to operate the computer.

The 4 Functions of a Computer

Function Meaning Example devices
1. Receive input Accept information from outside Keyboard, mouse
2. Process information Do arithmetic or logical operations (CPU)
3. Produce output Communicate information to the outside world Monitor, printer
4. Store information Keep information Hard disk, compact disk (CD)

The 3 Main Units of a Computer

(The slide calls them "three main functions", but they're really the 3 main units:)

① Input/Output Unit

  • A computer processes input data using a set of instructions and gives output.
  • The I/O unit = the unit used to get data & instructions into the computer and to display or print output.
  • Keyboard = main input device. Monitor = main output device.

② Central Processing Unit (CPU)

  • The "brain" of the computer — does all processing of input data.
  • In microcomputers, the CPU is built on a single chip / Integrated Circuit (IC) called a Microprocessor.
  • 5 parts of the CPU (memory trick: "A CRBC" → ALU, CU, Registers, Buses, Clock):
Part What it does
Arithmetic Logic Unit (ALU) Does arithmetic (add, subtract, multiply, divide) and logical operations (less than, equal to, greater than)
Control Unit (CU) Controls the transfer of data and instructions among units. Called the "Central Nervous System" of the computer — manages & coordinates all units. It gets instructions from memory, interprets them, and directs the computer's operation
Registers Small, high-speed circuits that store data, instructions, and memory addresses while the ALU works. Number/type of registers varies per CPU
Buses Data is stored in a register as a unit of 8 bits. Each bit travels on a separate wire; this group of 8 wires is a bus. A bus = connection between two components to transmit signals. 3 types: Data bus, Control bus, Address bus
Clock Measures & gives a fixed time slot for each micro-operation. The CPU works in sync with the clock pulse. Clock speed measured in Megahertz (MHz) = millions of cycles per second. Speed varies per model

③ Memory

  • Stores data, instructions, and information before, during, and after processing by the CPU.
  • It's a work area (physically a collection of integrated circuits) where the CPU keeps data & instructions.
  • 2 types: RAM and ROM
ROM (Read Only Memory) RAM (Random Access Memory)
Holds Essential instructions Data & instructions while programs run
Permanent? ✅ Permanent — NOT erased when switched off ❌ Temporary — erased when switched off
Read/Write? Read only Read/Write (user can read and write)
Why the name? You can only read it You can randomly use any location
Capacity (per slides) 64 KB to 256 KB 640 KB to several megabytes

Memory trick: RAM = Remove At Machine-off (temporary). ROM = Remains On Memory (permanent).

1.6 Input Devices — 2 Categories

Basic Input Devices Special Input Devices
Essential to operate a PC Not essential to operate a PC
Always required for basic input Used for special purposes
Keyboard, Mouse Trackball, Light Pen, Touch Screen, Joystick, Digitizer, Scanner, OMR, BCR, OCR, MICR, Voice-Input Devices

1.7 Keyboard (Lesson 2.1 version)

  • Most common input device for manual data entry.
  • Similar to an electric typewriter keyboard but with extra keys.
  • Standardized for all computers (PC, workstation, notebook).

5 Classes of keys:

  1. Letter keys — the 26 letters of the English alphabet, arranged like a typewriter.
  2. Digit keys — two sets: (a) the row second from the top (like a typewriter), and (b) the numeric keypad at the bottom right for quick one-hand number entry.
  3. Special character keys — < > ? / { } [ ] ( ) . " @ # $ % & * etc.
  4. Non-printable control keys — for backspace, next line (Enter), tab, moving the cursor up/down, insert, delete. Also the space bar at the bottom for spaces.
  5. Function keys — labeled F1, F2 … up to F15; pressing them invokes programs stored in the computer.

How a keyboard works:
Key pressed → electric signal produced → detected by the keyboard encoder → sends a binary code for that key → CPU.

  • Many keyboard types exist, but the 101-key keyboard is the most popular.
  • You learn each key best by actually working on a PC.

1.8 Mouse

  • Controls the movement of the cursor on the screen.
  • A small object you roll on a hard, flat surface.
  • Named after its shape (looks like a mouse).
  • Move the mouse → pointer moves the same direction.
  • Has at least 1 button, sometimes up to 3; functions depend on the program running.
  • 3 basic types: Mechanical, Opto-mechanical, Optical.
  • Wireless mice send movement to the computer wirelessly — convenient.
  • Touch panel displays don't need a mouse; touch an icon with a finger or pointing device (e.g., ballpoint pen) to open a program.

1.9 Other (Special) Input Devices

🔵 Trackball

  • Stationary pointing device with a ball you rotate to move the cursor — like an upside-down mouse.
  • The whole device stays in place → saves desk space, reduces wrist & arm strain.
  • You move the ball with fingers, thumb, or palm for precise control.
  • In laptops/notebooks: used instead of a mouse; a ball half inserted into the body, moved with fingers.
  • Considered better than a mouse because it needs little arm movement and less desk space.
  • How it works:
    • Sensors inside detect the ball's rotation along two axes.
    • Rolling the ball → sensors translate it into cursor movement.
  • Advantages:
    • Ergonomics — less arm/wrist movement, comfortable for long use, less strain.
    • Space-saving — stationary, no extra desk space needed.
    • Precision — with practice, very precise; good for detailed work like editing.

✏️ Light Pen

  • Pointing device shaped like a pen.
  • Used to select menu items or draw pictures on the monitor screen.
  • Made of a photocell + optical system in a small tube.
  • Press the tip → the photocell detects the screen location → sends a signal to the CPU.

👆 Touch Screen

  • Some special VDU (Visual Display Unit) devices have touch-sensitive screens.
  • Sensitive to human fingers; act as tactile devices.
  • You point to a selection on the screen instead of pressing keys.
  • Helps the user get information quickly.

🕹️ Joystick

  • Pointing device to move the cursor on the screen.
  • A stick with a spherical ball at both lower and upper ends.
  • The lower ball moves in a socket; can move in all four directions.
  • Works similar to a mouse.
  • Mainly used in CAD (Computer Aided Designing) and computer games.

🎨 Digitizer (Tablet / Graphics Tablet)

  • Converts analog information into digital form.
  • Can convert a signal from a TV or camera into numbers stored in a computer → computer can recreate the picture.
  • Also called Tablet / Graphics Tablet because it converts graphics & pictures into binary input.
  • Used for fine drawing work.

🖨️ Scanner (Flatbed / Handheld)

  • Works like a photocopy machine.
  • Used to transfer information on paper → to the computer's hard disk for editing.
  • Captures images → converts to digital form → stored on disk.
  • Images can be edited before printing.
  • Types shown: Flatbed scanner and Handheld scanner.

📝 OMR — Optical Mark Reader

  • Special optical scanner that recognizes marks made by pen or pencil.
  • Used where one out of a few choices is marked.
  • Mainly for checking multiple-choice exam answer sheets.

🏷️ BCR — Bar Code Reader

  • Optical scanner for bar-coded data (light and dark lines).
  • Bar codes are used for labeling goods, numbering books, etc.
  • Scans the bar code → converts to an alphanumeric value → sends it to the connected computer.

🔤 OCR — Optical Character Recognition

  • Optical scanner that reads printed text.
  • Scans character by character → converts to machine-readable code → stores in memory.
  • Used for: passenger tickets, credit card bills (computer-printed), ZIP codes in postal services.

🏦 MICR — Magnetic Ink Character Recognition/Reader

  • Mainly used in banks (many cheques processed daily).
  • Bank code number and cheque number are printed with special ink containing magnetic particles — machine readable.
  • This reading process = Magnetic Ink Character Recognition.
  • It's a technology that encodes info like bank routing numbers and account numbers using magnetic ink.
  • The ink's particles can be magnetized and then read by MICR readers.
  • Widely used in banking for checks and other financial documents.

🎤 Voice Input Devices

  • The latest input devices — recognize the human voice.
  • Microphone = voice input device; inputs sound stored in digital form.
  • Used for adding sound to multimedia presentations or mixing music.

🔑 Scanner-family cheat sheet (easy to mix up!)

Device Reads… Used for
OMR Marks (pencil/pen shading) Multiple-choice exam sheets
BCR Bar codes (lines) Goods labels, book numbers
OCR Printed text/characters Tickets, credit card bills, ZIP codes
MICR Magnetic ink characters Bank cheques

PART 2 — KEYBOARD FUNDAMENTALS (Lesson 2.2)

2.1 The Keyboard

  • One of the primary input devices.
  • You enter data by pressing keys.
  • Desktop keyboards: 101 to 105 keys. Laptops/smaller computers have fewer keys.
  • Lets you type letters, numbers, spaces, punctuation, and symbols like $ and *.
  • Has special keys for entering data and instructions.

2.2 Parts of the Keyboard (5 parts)

Part Description Examples
1. Typewriter keypad The typing area — letters, numbers, punctuation, basic keys. All keyboards have it A–Z, 0–9, punctuation
2. Numeric keypad On the right side of many desktop keyboards. Calculator-style: numbers, decimal point, basic math operators. Makes entering numbers easier 0–9, ., + - * /
3. Toggle keys Switch between two states (ON/OFF) Caps Lock, Num Lock, Scroll Lock, Insert
4. Special keys (a.k.a. Computer keys) Special commands Esc, Ctrl, Alt, Print Screen, Windows key, Mouse (menu) key
5. Function keys (F1–F12) Across the top; labeled F + number. Programmed to issue commands; what they do depends on the program. E.g., F1 = Help in many programs F1 … F12

⚠️ When told to "press F1", press the single key labeled F1 — NOT the letter F then the number 1.

⚠️ Note: Lesson 2.1 says function keys go up to F15; Lesson 2.2 says F1–F12 (the common standard today).

2.4 Typing Fundamentals

The 10-Finger Method (Touch Typing)

  • A well-established technique to use the keyboard efficiently.
  • With practice and correct finger positions you can type "blindly" (without looking).
  • Result: lower error rate + higher typing speed at the same time.

Hunt and Peck (the bad habit ❌)

  • Many people still do this despite the 10-finger method's advantages.
  • You stare at the keyboard until you find the key, then hit it with your index finger.
  • After years you may use more fingers and know key positions better — but without fixed finger-key combinations, few people can type blindly and equally fast.

Basic (Home) Position

  • Fingers rest in a fixed starting position from which you can reach any key.
  • Left hand: A, S, D, F
  • Right hand: J, K, L, ;
  • Thumbs: on the space bar
  • 💡 Tip: The F and J keys have a small bump — feel them with your index fingers to find home position without looking; the other fingers follow.

Fingers and Keys

  • Each finger is in charge of several keys (a color-coded chart shows which finger → which key).
  • Example: To hit E → use your left middle finger (its home key is D). Reach up to E, then return to D.

Objective of the 10-Finger Method

  • To make keyboard handling automatic — stored in your subconscious. The subconscious handles complex actions within seconds, almost automatically.
  • Hunt-and-peck wastes energy ("where's the next key?"). Fixed finger-key combos let you focus on what matters: the content.
  • 💡 Tip: If you've used your own style for a long time, you'll likely be slower at first after switching. Don't be discouraged — soon you'll type faster and more comfortably than before.

Advantages of Learning to Type (3)

  1. Speed — typing subconsciously increases speed a lot → saves precious time.
  2. Efficiency — you don't focus on single keys anymore, so you concentrate on the text. No switching back and forth → your brain gets relief and works better.
  3. Ergonomics — always looking at the keyboard causes unhealthy posture. With 10 fingers you don't need to look → you sit upright in a good position.

Do I Have to Use All 10 Fingers?

  • Using all 10 is the optimal way — faster and more relaxed.
  • But if retraining is very hard, or you have anatomical difficulties, you can use fewer fingers or different fingers than recommended.
  • What really matters: know the key positions and finger movements and use them without long thinking or looking at the keyboard.
  • The recommended technique is just a proven method — you may adapt it to your needs.

Why Is It Worth It?

  • 2/3 of all professional activities require computer work; we also spend more personal time in the digital world.
  • Daily typing time may seem small, but the long-term view matters.
  • Example calculation:
    • 1 hour/day of typing → 365 hours/year.
    • Double your speed → save about 180 hours/year.
    • On a 40-hour work week, that's 4½ weeks of free time per year (or at least you'd get to work on time more often 😄).
  • Depending on your current skill, even a 3–4× speed increase is possible → even more savings.

Typing speed vs. time spent (based on a 40-hour work week)

Words per minute Text input per day Time spent in 1 year Time spent in 5 years
10 wpm 2 hours 18 weeks 90 weeks
20 wpm 1 hour 9 weeks 45 weeks
40 wpm 30 minutes 4.5 weeks 22.5 weeks
60 wpm 20 minutes 3 weeks 15 weeks

Pattern: double the speed → half the time.

  • The time needed to learn 10-finger typing is negligible compared to the long-term savings.
  • If you're slow now, learning is definitely worthwhile.
  • Practice reference: https://www.typing.academy/10-finger-typing

PART 3 — OUTPUT DEVICES (Lesson 2.3)

3.1 What are Output Devices?

  • Hardware used to display or print the processed information.
  • Examples: Monitor (display screen), Printer, Plotter, Speaker, Computer Output Microfilm (COM), etc.

3.2 Monitor

  • Also called VDU (Visual Display Unit) — the main output device.
  • Forms images from tiny dots called pixels arranged in a rectangle.
  • Image sharpness depends on the number of pixels.

Classified by resolution (number of pixels):

Acronym Full name
CGA Colour Graphics Adapter
MDA Monochrome Display Adapter
HGA Hercules Graphics Adapter
EGA Enhanced Graphics Adapter
VGA Video Graphics Adapter
SVGA Super Video Graphics Adapter

Classified by colour:

  • Monochrome — single colour (black/white) display
  • Colour — displays all colours

3.3 Printer

  • The most important output device for printing information on paper.
  • 2 types: Impact and Non-Impact.

🗺️ Printer Family Tree (memorize this!)

PRINTERS
├── IMPACT (strikes ribbon onto paper)
│   ├── Character Printers (1 character at a time)
│   │   ├── Daisy Wheel Printer
│   │   └── Dot Matrix Printer
│   └── Line Printers (1 line at a time — faster)
│       ├── Drum Printer
│       └── Chain Printer
├── NON-IMPACT (no striking; 1 page at a time = "Page Printers")
│   ├── Laser Printer
│   └── Inkjet Printer
└── THERMAL (uses heat instead of liquid ink)
    ├── Direct Thermal Printer
    └── Thermal Transfer Printer

A. Impact Printers

  • Print by striking against the ribbon onto the paper.
  • 2 types: Character printers and Line printers.

Character Printers — print one character at a time:

  • Daisy Wheel Printer — uses a plastic or metal hub with spokes called a daisy wheel.
  • Dot Matrix Printer — prints characters by putting dots onto the paper.

Line Printers — print one line at a time; much faster than character printers:

  • Drum Printer — prints a line using a rotating drum with a ring of characters for each print position.
  • Chain Printer — prints a line using a rotating chain with ring characters for each print position.

B. Non-Impact Printers

  • Print without striking the ribbon onto the paper.
  • Print a complete page at a time → also called Page Printers.
  • 2 types: Laser and Inkjet.

Laser Printer

  • Looks and works like a photocopier.
  • Based on laser technology — a laser beam writes the image on paper.
  • Many models, depending on speed and number of dots printed.

Inkjet Printer

  • Non-impact — prints without striking a ribbon against paper.
  • Places tiny droplets of ink onto paper.
  • How it works (6 steps):
    1. Computer sends the document/image to the printer.
    2. Printer processes the information.
    3. Print head moves across the paper.
    4. Tiny ink droplets are placed on specific spots.
    5. Droplets combine to form letters, numbers, images, graphics.
    6. Paper moves through until printing is done.

C. Thermal Printer

  • Prints text/images using heat instead of traditional liquid ink.
Direct Thermal Thermal Transfer
Material Heat-sensitive paper Ribbon with ink or wax
How Print head heats areas of paper → heated areas turn dark Heat transfers material from ribbon onto paper/other material
Ink/toner? ❌ No ink or toner needed Uses ribbon (ink/wax)
Durability Less durable ✅ More durable prints
Used for Receipts, tickets, labels Product labels, barcodes, shipping labels

3.4 Plotter

  • Prints high-quality graphics and drawings.
  • For charts, drawings, maps in engineering and scientific applications.
Type How it works
Flat Bed Plotter Pen moves; paper/material is on a stationary flat surface
Drum Plotter Both the pen AND the drum (holding paper) move
Inkjet Plotter Uses inkjet instead of pen. Faster than flat bed; prints multi-coloured large drawings

3.5 Speakers

  • Popular output devices.
  • Receive audio input from the sound card → produce output as sound waves.
  • Most are active speakers — have an internal amplifier to increase volume (amplitude).
  • Usually come in pairs → produce stereo sound from two separate audio channels.

⚠️ EXAM TRAPS / EASY-TO-CONFUSE

  • ROM = permanent, RAM = temporary (erased when off).
  • CU = "Central Nervous System"; CPU = "Brain".
  • ALU does math AND logic (less than, equal, greater than).
  • Bus = group of 8 wires; 3 types: data, control, address.
  • Clock speed = MHz (millions of cycles per second).
  • Basic input = keyboard & mouse; everything else = special.
  • Mouse types: mechanical, opto-mechanical, optical.
  • Trackball = upside-down mouse; better than mouse (less arm movement, less space).
  • Joystick → CAD and games. Light pen → photocell.
  • Digitizer → analog to digital. OMR → exam sheets. MICR → bank cheques.
  • Most popular keyboard: 101 keys. Desktop: 101–105 keys.
  • Toggle keys: Caps Lock, Num Lock, Scroll Lock, Insert.
  • Home row: ASDF / JKL; — bumps on F and J.
  • QWERTY = most used; Dvorak = faster design, less used.
  • Character printers: Daisy wheel, Dot matrix. Line printers: Drum, Chain.
  • Non-impact = Page printers: Laser, Inkjet.
  • Laser printer works like a photocopier; scanner works like a photocopy machine too.
  • Direct thermal = no ink; thermal transfer = ribbon, more durable.
  • Drum plotter: pen AND drum move. Flat bed plotter: only pen moves.
