🔑 Press Enter only at the end of a paragraph, never at the end of each line. Word wraps lines by itself (word wrap).

1.2 Proofreading: Spelling, Grammar, Find & Replace

  • Spelling & Grammar check: Review › Proofing › Spelling & Grammar (F7). In M365 it is called Editor.
    • Red wavy underline = possible spelling error.
    • Blue double underline = possible grammar / style error.
    • Right-click the underlined word to see suggestions.
  • Find: Home › Editing › Find (Ctrl + F). This opens the Navigation Pane.
  • Replace: Home › Editing › Replace (Ctrl + H). Type Find what and Replace with, then Replace (one at a time) or Replace All.
  • Go To: Ctrl + G (or F5) jumps to a page, line, or footnote.

⚠️ Replace All can change words you did not mean to change (replacing "in" also hits "begin", "inside"). Use More › Find whole words only and Match case to be safe.

1.3 Changing Case (the ALL CAPS words: FRIENDS, HUSBAND, WIFE)

  • Home › Font › Change Case (Aa ▾): Sentence case · lowercase · UPPERCASE · Capitalize Each Word · tOGGLE cASE.
  • Shift + F3 cycles: lowercase → UPPERCASE → Capitalize Each Word.
  • Ctrl + Shift + A = All Caps font effect.

⚠️ Change Case › UPPERCASE actually retypes the letters as capitals. The All caps effect (Font dialog) only displays them as capitals; the real letters stay lowercase. Both look the same on screen.

1.6 Character Spacing (Font dialog › Advanced tab)

  • Spacing: Normal / Expanded / Condensed, By: ___ pt. Exercise #2 used Expanded spacing (about 1.5–2 pt).
  • Scale: stretches letters wider (e.g. 150%).
  • Position: Raised / Lowered by ___ pt. This moves text up or down without shrinking it, unlike superscript and subscript.

⚠️ Character spacing (space between letters, Font dialog) is NOT line spacing (space between lines, Paragraph dialog).

1.7 Footnotes vs a Typed Superscript

  • Footnote: References › Footnotes › Insert Footnote (Alt + Ctrl + F). Word puts an automatic superscript number (¹) in the text and the matching note at the bottom of the page. It renumbers itself if you add more.
  • Endnote: References › Insert Endnote (Alt + Ctrl + D). The note goes at the end of the document.
  • Typing "1" and clicking Superscript only looks like a footnote. It does not create the note or renumber itself.

🔑 Footnote = foot (bottom) of the page. Endnote = end of the document.

2.1 Paragraph Alignment (Home › Paragraph) — Exercise #3

Center Ctrl + E Centered between margins (titles)
Align Right Ctrl + R Straight right edge (dates, signatures)

⚠️ Alignment applies to the whole paragraph, even if you only select one word.

2.2 Indents — Exercise #3 used all four kinds

Path: Home › Paragraph launcher ↘ › Indents and Spacing › Indentation (or Layout › Paragraph › Indent), or drag the markers on the ruler (View › Ruler).

Indent What moves Exercise #3 value Ruler marker

  • Ctrl + T = hanging indent · Ctrl + Shift + T = remove it.
  • Home › Increase / Decrease Indent buttons move the left indent 0.5" at a time.

🔑 Hanging = the first line "hangs out" to the left, like a hanger. It is used in bibliographies / references and numbered lists.
⚠️ First-line indent ≠ pressing Tab. Both look similar, but the indent is a paragraph setting, so every new paragraph gets it automatically.

2.3 Line & Paragraph Spacing

  • Line spacing = space between lines inside a paragraph. Home › Line and Paragraph Spacing (↕) › 1.0 / 1.15 / 1.5 / 2.0, or the Paragraph dialog › Line spacing: Single, 1.5 lines, Double, At least, Exactly, Multiple.
    • Ctrl + 1 single · Ctrl + 5 1.5 lines · Ctrl + 2 double. Exercise #3 used 1.5 and double.
  • Paragraph spacing = space before / after a paragraph. Layout › Paragraph › Spacing Before / After (in pt). Ctrl + 0 adds or removes 12 pt before.

2.4 Drop Cap — Exercise #4 (the file says "Drop Crop", but the feature is Drop Cap)

  • What: a big first letter at the start of a paragraph, like in storybooks and magazines.
  • Path: click in the paragraph → Insert › Text › Drop Cap › Dropped or In margin › Drop Cap Options…
  • Drop Cap Options:
    • Position: None · Dropped (letter sits inside the text, the lines wrap around it) · In margin (letter sits outside, in the left margin)
    • Font: you can give the big letter a different font (Exercise #7 used Matura MT Script Capitals)
    • Lines to drop: how many lines tall the letter is. Default = 3. Exercise #4 used 3 and 4; #7 used 2 and 3.
    • Distance from text: gap between the letter and the paragraph
  • Word turns the letter into a frame. To remove it, use Drop Cap › None.

⚠️ The drop cap applies to the first letter of the paragraph the cursor is in. Don't select the whole paragraph.
⚠️ The ribbon is under Insert, not Home or Layout.

2.5 Columns (Exercise #4 had a 2-column section; the final project requires columns)

  • Layout › Page Setup › Columns › One / Two / Three / Left / Right / More Columns… (number, width, spacing, Line between, Apply to: Selected text / This point forward / Whole document).
  • To put only part of the page in columns, select that text first. Word adds section breaks around it automatically.
  • Column break: Layout › Breaks › Column (Ctrl + Shift + Enter) forces the text to the next column.
  • Page break: Ctrl + Enter.

2.6 Inserting Pictures (Exercises #4 and #9)

  • Insert › Illustrations › Pictures › This Device… (or Stock Images / Online Pictures).
  • Picture Format tab (appears when the picture is selected): Wrap Text (In Line with Text, Square, Tight, Behind Text, In Front of Text, Top and Bottom), Crop, Picture Styles, Picture Border, Corrections / Color / Artistic Effects, Remove Background, Size (height / width).
  • Drag a corner handle to resize without distorting. Hold Shift to keep proportions.

⚠️ A new picture is In Line with Text by default, so it acts like one big letter and won't move freely. Change Wrap Text to Square or Tight first.

2.7 Tab Stops — Exercise #5 "Tab Stop Position"

What: a tab stop is a position on the ruler where the cursor jumps when you press Tab. Use tabs (not spaces) to line up columns of text.

The 5 tab types (click the tab selector at the left end of the ruler to switch):

Tab Symbol Text lines up… Use for
Left └ starting at the stop, going right Normal columns
Center ┴ centered on the stop Centered headings in a column
Right ┘ ending at the stop Page numbers in a table of contents, prices
Decimal ┴· on the decimal point Money (1,950.00 / 3,910.00)
Bar │ draws a vertical line at the stop Separating columns

Exercise #5 used left, center, right, and bar tabs, plus a right tab at 5.5" with a DOT LEADER.

Leader = the characters that fill the gap before the tab stop:
1 None · 2 ........ (dots) · 3 -------- (dashes) · 4 ________ (solid line)

Steps — table-of-contents style ("Introduction to Computer ……… i"):

  1. Select the lines (or click on an empty line before typing).
  2. Home › Paragraph launcher ↘ › Tabs… (button at the bottom-left of the Paragraph dialog). Shortcut: double-click any tab stop on the ruler.
  3. Tab stop position: 5.5" → Alignment: Right → Leader: 2 ....... → click Set → OK.
  4. Type Introduction to Computer, press Tab, type i. The dots fill in by themselves.

Price list ("Windows, MS Word, Excel ……… 1,950.00"): same steps. Use a right (or decimal) tab with a dot leader so the amounts line up on the right.

⚠️ In the Tabs dialog you must click Set before OK, or the tab isn't saved.
⚠️ Never line up columns with the spacebar. They will never line up exactly.
⚠️ To remove a tab stop, drag it off the ruler, or use Tabs dialog › Clear / Clear All.
🔑 A leader is set on the tab stop, not typed. If you type dots by hand, it's wrong.

PART 3 — WORD: BULLETS, NUMBERING, BORDERS & SHADING (Exercises #6–#7)

3.1 Bullets and Numbering — Exercise #6 "The Ten Commandments of Love"

  • Bullets: Home › Paragraph › Bullets ▾ (• ○ ▪ ◆ ✓ …).
  • Numbering: Home › Paragraph › Numbering ▾ (1. 2. 3. / a) b) c) / i. ii. iii. / A. B. C.).
  • Multilevel List: Home › Paragraph › Multilevel List (1. → a. → i.).
    • Tab (or Increase Indent) = demote to the next lower level (1. → a.)
    • Shift + Tab (or Decrease Indent) = promote to a higher level
    • Exercise #6 used levels with •, o, and ▪ bullets.
  • Custom bullet: Bullets ▾ › Define New Bullet… › Symbol… (Wingdings / Symbol fonts) · Picture… (a picture bullet: Exercise #6 used a small .gif image) · Font… (bullet color / size) · Alignment.
  • Custom number: Numbering ▾ › Define New Number Format (style, format like "Rule 1:", font).
  • Restart / continue numbering: right-click the number › Restart at 1 / Continue Numbering / Set Numbering Value…
  • Quick auto-list: type 1. or * + space at the start of a line (AutoFormat As You Type).

⚠️ Press Enter twice (or Backspace on the empty bullet) to end a list.
⚠️ A picture bullet comes from Define New Bullet › Picture, NOT from Insert › Pictures.

3.2 Borders and Shading — Exercise #7

Three different kinds of border. Know where each one lives:

Kind Path Applies to
Text / paragraph border Home › Paragraph › Borders ▾ › Borders and Shading… › Borders tab Apply to: Text (box around the words only) or Paragraph (box from margin to margin)
Page border Design › Page Background › Page Borders (opens Borders and Shading on the Page Border tab) Whole document / This section / This section – first page only

Borders tab settings: Setting (None, Box, Shadow, 3-D, Custom) · Style (solid, dotted, double, wavy…) · Color · Width (½ pt … 6 pt) · Preview (click the sides to turn each line on or off) · Options (distance from text).

Page Border extra: Art ▾. These are picture borders (apples, hearts, stars, trees…). Exercise #7 used the apples art border on the whole page.

Shading tab: Fill (background color; Exercise #7 used blue fill) · Pattern Style / Color (dots, stripes) · Apply to: Text / Paragraph.

  • Quick shading: Home › Paragraph › Shading (paint bucket).

⚠️ Page Border is on the DESIGN tab (Page Background group), not Layout and not Insert. In Word 2010 it was on Page Layout, so old handouts may say "Page Layout".
⚠️ Shading ≠ Highlight. Highlight (Home › Font, marker icon) colors behind text only. Shading can fill the whole paragraph width.
⚠️ "Apply to: Text" vs "Paragraph" gives a different box. Text = one box per line around the words. Paragraph = one rectangle margin to margin.

3.3 Decorative Fonts & Frames

4.1 Mail Merge — Exercise #8 (memo "CALL CENTER LAUNCHED")

What: making many personalized copies of one document (letters, memos, invitations, certificates, envelopes, labels) by combining:

Part Meaning In Exercise #8
Main document The text that is the same for everyone, with placeholders The memo: TO / FROM / DATE / SUBJECT + body
Data source The list of recipients (table: 1 row = 1 person, 1 column = 1 field) Excel file Exercise #8 – Mail Merge Data Source.xlsx (an Access .mdb was also made)
Merge fields Placeholders shown in «chevrons» that get replaced by data «Title» «Name» «Designation» «Address»
Merged document The final output: one copy per record One memo per recipient

Steps (Mailings tab):

  1. Mailings › Start Mail Merge › Start Mail Merge ▾ › Letters (also: E-mail Messages, Envelopes, Labels, Directory, Step-by-Step Mail Merge Wizard).
  2. Select Recipients ▾ › Use an Existing List… → browse to the Excel file → choose the sheet (e.g. Sheet1$) → tick "First row of data contains column headers" → OK. (Or Type a New List… to create one inside Word.)
  3. (Optional) Edit Recipient List to sort, filter, or untick people.
  4. Put the cursor where each field goes → Insert Merge Field ▾ › Title, Name, Designation, Address. (Address Block and Greeting Line are ready-made combos.)
  5. Preview Results → use the ◀ ▶ arrows to check each record.
  6. Finish & Merge ▾ › Edit Individual Documents… (makes a new document with all the letters, e.g. Letters1) / Print Documents… / Send E-mail Messages… → All → OK.

⚠️ You can't type « » yourself. Typed chevrons are plain text. Fields must come from Insert Merge Field. (Alt + F9 shows the real field codes: { MERGEFIELD Name }.)
⚠️ The Excel data source needs column headers in row 1. Those headers become the field names.
⚠️ Close the Excel file before connecting, or Word may not be able to open it.
🔑 Final project: mail merge with at least 20 recipients, producing a letter, invitation, or certificate.

4.3 Table of Contents (Final Project requirement)

5.2 Entering & Editing Data (Editing Worksheet)

  • Type, then Enter (go down) or Tab (go right). Esc cancels.
  • F2 = edit the active cell in place. Double-clicking the cell also works.
  • Alt + Enter = new line inside a cell.
  • Ctrl + Enter = put the same entry into all selected cells.
  • Fill handle: drag down / right to copy a formula or continue a series (1, 2, 3 · Jan, Feb · 13-001, 13-002). Double-click the fill handle to fill down to the end of the data.
  • Ctrl + D = fill down · Ctrl + R = fill right.
  • Insert / delete rows & columns: right-click the row number or column letter › Insert / Delete (or Home › Cells › Insert / Delete).
  • Column width: drag the border between column letters, or double-click it to AutoFit.

5.4 Formulas: The Basics (Simple Operation sheet)

  • Every formula starts with =. Without it, Excel treats it as text.
  • Use cell references (J5), not typed numbers (8000), so results update when the data changes.

Operators:

Operator Meaning Example
+ - add, subtract =K5+L5+M5
* multiply =J5*10%
/ divide =C5/24/8
^ power =2^3 → 8
% percent 10% = 0.10
& join text =E5&", "&F5 → Santos, Evangeline
= <> > < >= <= compare (used in IF) =J5>=4500

Order of operations (Excel): ( ) → negation (-) → % → ^ → * and / (left to right) → + and - (left to right) → & → comparisons.

🔑 PEMDAS. Parentheses first, then multiply/divide, then add/subtract.
⚠️ =A1+B1/2 divides only B1 by 2. To average two cells, write =(A1+B1)/2.

5.5 Relative vs Absolute vs Mixed References

Type Written When copied down/right… Use for
Relative J5 changes (J6, J7…) Normal row-by-row formulas
Absolute $J$5 never changes A single fixed cell (tax rate cell, lookup table)
Mixed $J5 / J$5 only the part without $ changes Locks only the column or only the row
  • Press F4 while the cursor is on a reference to cycle: J5 → $J$5 → J$5 → $J5 → J5.
  • $ = "lock". The $ goes in front of whatever must not move.

Example: the tax rate 10% is in cell B1. In row 5 write =J5*$B$1, then fill down. Row 6 becomes =J6*$B$1 (J changed, B1 stayed).
If you forgot the $: row 6 becomes =J6*B2 → B2 is empty → the result is 0. Wrong!

⚠️ Lookup tables must be absolute: Lookup!$B$2:$C$12. Without $, the table range slides down as you copy and the bottom rows give #N/A or wrong answers.

PART 6 — EXCEL FUNCTIONS: SUM…MAX, IF, NESTED IF, VLOOKUP / HLOOKUP (Exercise #10, part 2)

6.1 Function Syntax

=FUNCTION(argument1, argument2, …)

  • Colon : = a range, "from…to": SUM(J5:J9) = J5+J6+J7+J8+J9.
  • Comma , = separate items: SUM(J5,P5,Q5) = only those 3 cells.

6.3 IF — Making a Decision

Syntax: =IF(logical_test, value_if_true, value_if_false)

📌 (exam item) Exercise #10 Employee Salary (Part-time / Fulltime):
=IF(J5<4500,"Part-time","Fulltime")
→ J5 = 8,000 → is 8000 < 4500? No → Fulltime. J5 = 4,300 → Part-time.

Rules:

  • Text results go in "double quotes": "PASSED". Numbers and cell references don't: 15%, H6.
  • The result can be a number or a formula: =IF(F6>100000,15%,10%).
  • Comparison operators: > < >= <= = <> (not equal).

⚠️ > vs >=: "75 and above passes" means >=75. Writing >75 makes a student with exactly 75 FAIL.
⚠️ Forgetting the quotes (=IF(I5>=75,PASSED,FAILED)) gives #NAME?.

6.4 Nested IF — More Than Two Outcomes

Put another IF in the value_if_false slot. With n outcomes you need n − 1 IFs, and the formula ends with that many closing parentheses.

📌 (exam item) MP4 Final Grade: A ≥ 98, B ≥ 90, C ≥ 85, D ≥ 80, E ≥ 75, else F

=IF(G6>=98,"A",IF(G6>=90,"B",IF(G6>=85,"C",IF(G6>=80,"D",IF(G6>=75,"E","F")))))

6 grades → 5 IFs → 5 closing ")))))".

How Excel reads it (G6 = 92): ≥98? no → ≥90? yes → "B". It stops at the first TRUE.

⚠️ Order matters. With >=, test from the HIGHEST down. If you test G6>=75 first, a 99 would be labelled "E", because 99 ≥ 75 is already TRUE.
(If you test from the lowest up, use < instead: =IF(G6<75,"F",IF(G6<80,"E",…)).)

6.5 VLOOKUP and HLOOKUP

VLOOKUP = Vertical lookup. The table is arranged in columns, and the lookup value is searched down the first column.
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

HLOOKUP = Horizontal lookup. The table is arranged in rows, and the lookup value is searched across the first row.
=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])

Argument Meaning
lookup_value What you are looking for (the salary, the score)
table_array The lookup table. Lock it with $
col_index_num / row_index_num Which column (or row) of the table to return. Count from 1 = the first column/row of the table, not column A
range_lookup TRUE (or omitted) = approximate match · FALSE (or 0) = exact match

📌 (exam item) Exercise #10 Lookup sheet:

  • Salary Level table (vertical, Lookup!B: Salary 1,000 / 2,000 / … / 10,000, C: SL-1 … SL-10)
    =VLOOKUP(J5,Lookup!$B$2:$C$12,2) → J5 = 8,000 → SL-8. J5 = 5,500 → SL-5 (largest value ≤ 5,500 is 5,000).
  • Bonus table (horizontal, Lookup!F2:O2 salaries 1,000 … 10,000; F3:O3 bonus 100 … 1,000)
    =HLOOKUP(J5,Lookup!$F$2:$O$3,2) → 8,000 → 800. 5,500 → 500.
  • Lookup! = the cell is on another sheet named Lookup. If the sheet name has spaces: 'Sub Total'!A1.

6.6 Exact vs Approximate Match (and why the table must be SORTED)

Approximate — TRUE / 1 / omitted Exact — FALSE / 0
Finds The largest value ≤ the lookup value Only an identical match
Table order MUST be sorted ASCENDING (smallest → largest) in the first column/row Any order
If not found Returns the closest lower bracket. If the value is smaller than the first entry → #N/A #N/A
Use for Ranges / brackets: score→grade, salary→level, tax tables IDs / codes / names: Employee No. → name, product code → price

Why sorted ascending? Approximate mode doesn't check every row. It does a fast search that assumes the numbers go up, and it stops where the next value would be too big. If the table is out of order, Excel stops in the wrong place and returns a wrong answer with no error message.

⚠️ VLOOKUP with the 4th argument left out = TRUE (approximate). Exercise #10 left it out, which works only because the tables were sorted ascending.
⚠️ Approximate: a salary below the first value (e.g. 500 when the table starts at 1,000) → #N/A. That's why MP2's table starts at 0.
⚠️ col_index_num larger than the number of columns in the table → #REF!. Less than 1 → #VALUE!.
⚠️ VLOOKUP can only look to the right of the first column. The lookup column must be the leftmost column of table_array.

  • Theme (colors + fonts + effects + background together): Design › Themes gallery (Film Burn, Ion, Facet…) · Variants (color/font/background versions of the theme).
  • Background: Design › Format Background › Solid / Gradient / Picture or texture fill / Pattern › Apply to All.
  • Slide size: Design › Customize › Slide Size › Widescreen (16:9) / Standard (4:3) / Custom.
  • Slide Master (change the layout/fonts for ALL slides): View › Slide Master.

10.3 Pictures (the main skill in Exercise #11)

  • Insert › Images › Pictures › This Device… (or click the picture icon inside a picture placeholder).
  • Full-slide (full-bleed) picture: drag the corners to the slide edges, or Picture Format › Size = slide width × height (13.333" × 7.5"), then Arrange › Align › Align Center / Align Middle.
  • Picture Format tab:
    • Remove Background → mark areas to keep / remove → Keep Changes (makes a cut-out, like the transparent character PNG)
    • Color › Recolor › Grayscale (or Black and White / Washout) → the black-and-white version
    • Corrections (brightness / contrast / sharpness) · Artistic Effects · Transparency
    • Crop (also Crop to Shape, Aspect Ratio) · Picture Styles · Picture Border / Effects
    • Arrange: Bring Forward / Send Backward, Selection Pane (rename and hide objects, like "Multiverse"), Group (Ctrl + G)
  • Reset Picture undoes all the picture formatting.

🔑 To make a gray→color reveal yourself: insert the color picture → Duplicate Slide (Ctrl + D) → on the first copy set Color › Grayscale → give the second slide a Fade transition.

10.4 Transitions (effects BETWEEN slides)

  • Transitions tab › gallery: Subtle (Fade, Push, Wipe, Split, Reveal, Cut, Random Bars, Shape, Uncover, Cover, Flash, Morph) · Exciting (Curtains, Wind, Prestige, Fracture, Crush, Peel Off, Page Curl, Airplane, Origami, Dissolve, Checkerboard, Blinds, Clock, Ripple, Honeycomb, Glitter, Vortex, Shred, Switch, Flip, Gallery, Cube, Doors, Box, Comb, Zoom, Random) · Dynamic Content (Pan, Ferris Wheel, Conveyor, Rotate, Window, Orbit, Fly Through).
  • Effect Options (direction / variant) · Sound · Duration (seconds, e.g. 01.50) · Apply To All.
  • Advance Slide: On Mouse Click and/or After: 00:05.00 (automatic timing).
  • The transition belongs to the slide it goes INTO. Exercise #11's slide 1 had none; slides 2–4 had Fade.
  • Morph (M365 / 2019+): duplicate a slide, move or resize objects on the copy, apply Morph to the copy, and the objects glide smoothly between positions.

10.5 Animations (effects on OBJECTS inside a slide)

Select an object → Animations tab.

Type Color Meaning Examples
Entrance Green Object appears Appear, Fade, Fly In, Float In, Split, Wipe, Zoom, Bounce
Emphasis Yellow/Gold Object draws attention while already on screen Pulse, Spin, Grow/Shrink, Teeter, Color Pulse
Exit Red Object leaves Disappear, Fade, Fly Out, Zoom
Motion Paths (lines) Object moves along a path Lines, Arcs, Turns, Loops, Custom Path
  • Effect Options (direction, by paragraph) · Animation Pane (list + order of all animations, Play From) · Add Animation (adds a second effect to the same object; picking from the gallery instead replaces it) · Animation Painter (copy an animation to another object, like Format Painter).
  • Timing group:
    • Start: On Click · With Previous (same time as the one before) · After Previous (right after the one before finishes)
    • Duration (speed) · Delay · Reorder: Move Earlier / Move Later
    • Trigger › On Click of [object]: the animation plays when you click a specific object. This is how an interactive slide is built (click a planet → its info box appears).
  • The numbers 1, 2, 3 beside objects in Normal view = the click order.

⚠️ Transition = between slides (Transitions tab). Animation = an object inside a slide (Animations tab). This is the #1 PowerPoint exam trap.
⚠️ Choosing a new effect from the gallery replaces the old one. Use Add Animation to stack effects.

10.6 Interactive Presentation (Final Project topic option)

  • Hyperlink to another slide: select text/shape/picture → Insert › Links › Link (Ctrl + K) › Place in This Document → pick the slide. Hyperlinks only work in Slide Show view.
  • Action (Insert › Links › Action) › Mouse Click / Mouse Over › Hyperlink to: Next / Previous / First / Last slide / a specific slide / URL / Run program, plus sound.
  • Action Buttons: Insert › Shapes › Action Buttons (◀ Back, ▶ Next, 🏠 Home, ⏮ Beginning, ⏭ End, ↩ Return). The Action Settings box opens automatically.
  • Zoom: Insert › Links › Zoom › Summary Zoom / Section Zoom / Slide Zoom (a clickable thumbnail menu).
  • Triggers (10.5) + Morph (10.4) = animated, interactive feel.
  • Media: Insert › Media › Video › This Device / Online Video · Audio › Audio on My PC → Playback tab: Start Automatically / When Clicked On, Play Across Slides, Loop until Stopped, Hide During Show, Trim.

⚠️ EXAM TRAPS / EASY-TO-CONFUSE

Confusing pair How to tell them apart
Drop Cap vs "Drop Crop" The feature is Drop Cap (Insert › Text). "Crop" is cutting a picture (Picture Format › Crop)
Footnote vs Endnote Foot = bottom of the page · End = end of the document
Superscript vs Subscript Super = up (x², ¹) Ctrl + Shift + = · Sub = down (H₂O) Ctrl + =
Character spacing vs Line spacing Between letters (Font › Advanced) vs between lines (Paragraph)
First-line vs Hanging indent First line in vs first line out (all other lines in)
Right tab vs Decimal tab Right = text ends at the stop · Decimal = lines up the decimal point
Page border vs Paragraph border Page border = Design tab, whole page, Art borders · Paragraph border = Home › Borders
Shading vs Highlight Shading = paragraph background (Borders and Shading) · Highlight = marker behind text (Home › Font)
Main document vs Data source Main = the letter with «fields» · Data source = the Excel/Access list
Merge Cells vs Split Cells Merge = many → one · Split = one → many
Tab vs Ctrl + Tab in a table Tab = next cell · Ctrl + Tab = tab character
Colon vs Comma in functions J5:Q5 = range (all cells) · J5,P5,Q5 = only those cells
Relative vs Absolute J5 moves when copied · $J$5 stays (F4)
> vs >= "75 and above" = >=75. >75 fails a 75
Text in IF Text needs "quotes". Numbers (15%) don't
Nested IF order With >=, test from highest to lowest
VLOOKUP vs HLOOKUP V = table in columns · H = table in rows
TRUE vs FALSE in lookup TRUE/omitted = approximate, table sorted ascending, for ranges · FALSE = exact, for IDs
col_index_num Counts from the table's first column, not from column A
#N/A vs #NAME? vs #REF! Not found · misspelled / missing quotes · deleted reference
##### Not an error. Widen the column
Filter vs Subtotal Filter hides rows · Subtotal adds total rows (sort first!)
Print Area vs Print Titles Area = what prints · Titles = header rows repeated on every page
Freeze Panes vs Print Titles Freeze = screen only · Print Titles = paper
CF "Equal To" vs formula rule Equal To colors only that cell · formula with $H6 can color the whole row
Transition vs Animation Between slides (Transitions tab) vs objects on a slide (Animations tab)
With Previous vs After Previous Same time vs right after
F5 vs Shift + F5 From beginning vs from current slide
Gallery effect vs Add Animation Gallery replaces · Add Animation adds
